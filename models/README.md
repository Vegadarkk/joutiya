Local ONNX models of the media worker (nudity score, face count; design D7). `MANIFEST.json` pins each file's URL, revision, sha256, licence and tensor layout; `node scripts/fetch-models.ts` downloads them into `MEDIA_MODELS_DIR` (default `./models`) and verifies the checksums, the Docker worker target does the same at build time, and the weights are never committed (`.gitignore`). Without the files the worker falls back to a stub classifier (score 0, no face) and logs a warning outside development. Details in French: `docs/models.md`.
