Local ONNX models of the media worker (nudity score, face count; design D7). `MANIFEST.json` pins each file's URL, revision, sha256, licence and tensor layout; `node scripts/fetch-models.ts` downloads them into `MEDIA_MODELS_DIR` (default `./models`) and verifies the checksums, the Docker worker target does the same at build time, the CI `checks` job too (cached per MANIFEST, for the real-model test), and the weights are never committed (`.gitignore`). Without the files only development falls back to a stub classifier (score 0, no face); any other environment fails closed: every photo check throws, the upload ends refused after the retries and a P1 alert goes out. Details in French: `docs/models.md`.
